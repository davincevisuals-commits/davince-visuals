# Davince Visuals

A professional photography, film production, and digital art website based in Uganda.

## 🌐 Live Site

[davincevisuals.com](https://davincevisuals.com)

## 📁 Project Structure

```
davince-visuals/
├── index.html          # Main website (single-page)
├── thankyou.html       # Form submission confirmation page
├── davince-logo.png    # Brand logo
├── background.jpg      # Hero background image
├── portfolio1.jpg      # Portfolio gallery images
├── portfolio2.jpg
├── portfolio3.jpg
├── portfolio4.jpg
├── portfolio5.jpg
├── vision-editor.png   # Product/software screenshot
└── CNAME               # Custom domain configuration
```

## ✨ Features

- Responsive single-page website
- Portfolio gallery with lightbox viewer
- Before/after photo comparison slider
- Booking/contact form
- WhatsApp chat widget
- Light/dark mode toggle
- Embedded Google Maps
- JSON-LD structured data for SEO

## 🛠️ Services

- **Photography** – Weddings, portraits, commercial shoots
- **Film Production** – Cinematic storytelling and video production
- **Digital Art** – Creative digital artwork and design
- **IT Solutions** – Technical support and creative software

## 🚀 Deployment

The site is hosted on GitHub Pages with a custom domain configured via the `CNAME` file.

To deploy updates:
1. Commit and push changes to the `main` branch
2. GitHub Pages automatically publishes from `main`
